# 4. Iteracije

Repo je blueprint: svaka iteracija dorađuje problem ili rješenje. Ovdje se
bilježi što se promijenilo i što je ostalo otvoreno.

## Iteracija 1 — 2026-10-18

- Postavljena vizija i misija (README).
- Dokumentirano trenutno stanje: lanac vlasti (izborni prag → Sabor →
  Savjet HNB-a → licenca) i lanac novca (porezi → proračun → depoziti →
  strane banke → dobit).
- Rješenje 02 (1 osoba = 1 glas): tri sloja (pravilo, identitet,
  provjerljivost), opcije A–E za izborni sustav, polazna preporuka B + E.
- Rješenje 03 (P2P likvidnost): kriteriji pravednosti, šest slojeva, život
  zajma, uloga države, pravni put u fazama 0–4, rizici.
- Karta postojećih projekata u ekosustavu (04) i praznina koju nitko još
  nije pokrio.
